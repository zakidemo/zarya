# Zarya

[English](README.md) · **العربية**

</div>

<div dir="rtl">

**لغة صغيرة لمنطق المواقع الآمن.**
البرنامج يصرّح بما يحق له قراءته، وملصق ثابت يخبرك بما قد يُخرجه، قبل أن يُشغَّل.

> [!WARNING]
> Zarya نموذج بحثي تجريبي (الإصدار 0.0.18-dev.14). لم يخضع لتدقيق أمني مستقل، وليس مخصصًا للمواقع الحقيقية بعد.

## لماذا Zarya؟

أغلب ثغرات الويب تتكرر: استعلام SQL يُبنى من مدخلات المستخدم، وطلبات لا يتحقق منها أحد، وكود يستطيع قراءة أي ملف على الخادم. وجزء متزايد من هذا الكود يكتبه الذكاء الاصطناعي دون مراجعة.

في Zarya لا يمكن كتابة هذه الأخطاء أصلًا:

- 🔒 **قراءة المصرَّح به فقط:** البرنامج يذكر كل مورد يحق له قراءته، مثل `permission text courses;`، ولا يصل إلى غيره.
- 🚫 **لا عمليات خطيرة:** لا يوجد في اللغة SQL ولا ملفات ولا شبكة ولا كتابة. المضيف ينفّذ استعلامات ثابتة للقراءة فقط.
- 📐 **عقود صارمة:** المخططات ترفض الحقول غير المتوقعة والأنواع الخاطئة، وعقود المخرجات ترفض أي استجابة فيها بيانات غير مصرَّح بها.
- 🏷️ **الملصق:** الأمر `zarya --label-ar` يخبرك، دون تشغيل البرنامج، ماذا يقرأ وأي الحقول قد تصل إلى المخرجات.
- 🦀 **محرّك آمن الذاكرة:** مكتوب بـ Rust، ويمنع الشيفرة غير الآمنة كليًا، ولا يعتمد على أي مكتبة خارجية.

## الملصق

</div>

```text
$ zarya --label-ar cheap_courses.zr
ملصق Zarya (تحليل ثابت؛ لم يُشغَّل البرنامج)
يقرأ: courses
بيانات قد تظهر في المخرجات:
  courses: الحقول id، title
بيانات تُستخدم في الشروط:
  courses: الحقول price_minor؛ هل هو صالح
ملاحظات: لا شيء
```

<div dir="rtl">

البرنامج يستخدم `price_minor` في التصفية، لكنه لا يُخرجه أبدًا، والملصق يقول ذلك بوضوح.

## عرض الهجمات

جرّبنا أربع هجمات معروفة على بحث PHP مكتوب بشكل سيئ عمدًا، وعلى البرنامج نفسه مكتوبًا بـ Zarya:

| الهجوم | PHP البسيط | Zarya |
|---|---|---|
| حقن SQL في خانة البحث | ❌ سرّب بريد الموظفين وكلمات المرور المشفّرة | ✅ عومل كنص عادي |
| نص في مكان رقم | ❌ سرّب دورة غير منشورة | ✅ رُفض الطلب |
| المبرمج أعاد عمودًا خاصًا بالخطأ | ❌ سرّب عمود التكلفة | ✅ عقد المخرجات رفضه |
| كود يقرأ ملف الأسرار (بطريقتين) | ❌ قرأ الملف | ✅ الصلاحية مرفوضة |

كود PHP المكتوب بعناية يصدّ الهجمات الثلاث الأولى أيضًا. الفرق أن النسخة غير الآمنة لا يمكن كتابتها في Zarya. كل البيانات وهمية، والتجربة محلية.

## التشغيل

تحتاج [Rust](https://www.rust-lang.org/tools/install). ولعرض الهجمات تحتاج أيضًا Python 3 وPHP مع SQLite3.

</div>

```bash
cd runtime/rust
cargo build --release --offline
cargo test --release --offline
./target/release/zarya --label-ar ../examples/cheap_courses.zr

cd ../..
python -I -X utf8 run_demo.py
```

<div dir="rtl">

على Windows الملف التنفيذي هو `target\release\zarya.exe`.

## الحدود

- الملصق مصمَّم ليبالغ ولا ينقص. هذا **مُختبَر** (14 اختبارًا و29 برنامجًا مخادعًا)، وليس **مُبرهَنًا رياضيًا**.
- يغطي القيم والشروط، ولا يغطي التوقيت ولا توقّف البرنامج بخطأ.
- اللغة تقرأ وتطبع فقط: لا كتابة ولا جلسات ولا رفع ملفات حتى الآن.
- أمان ذاكرة المحرّك لا يحمي خادمًا محرّك PHP فيه معطوب. Zarya هنا عملية منفصلة، وليست بديلًا عن PHP.
